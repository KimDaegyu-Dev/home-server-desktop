# Hermes 도구 세트 축소 진행 보고

일반 프로필은 기존 도구 세트 18개를 유지하고, 역할별 프로필은 13개로 줄이는 설계를 확정했습니다. 첫 번째 검증 작업인 N1은 실행 중입니다. 실제 프롬프트 크기 감소량과 작업 기능 보존 여부는 아직 미검증 상태입니다.

## 확인한 결과

전역 설정인 `agent.disabled_toolsets`는 역할별 축소에 부적합합니다. 전역 설정은 기본 프로필에도 영향을 미치므로 역할별 설정을 별도로 구성하기로 했습니다.

## 남은 사항

N1이 기준 측정값과 프로필별 측정 유효성을 확인한 뒤에 후속 변경 작업이 시작됩니다. Kanban 도구 세트 제거는 실제로 배정된 작업 카드에서 도구 사용 가능 여부를 확인한 후 결정합니다.

## 추적 정보

작업 N1은 기준 측정 및 측정 도구 검증을 담당합니다. 정확한 카드 ID는 원본 작업 기록에 보존합니다.
